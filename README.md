# QuantumVRP — Quantum-Classical Optimization for Vehicle Routing Problems

**QuantumVRP** is a research project from The University of Melbourne's Master of Computer Science (MCS) program by Drestanto Muhammad Dyasputro, exploring the application of quantum and hybrid quantum-classical methods to classical Vehicle Routing Problems (VRP).

---

##  Project Overview

This repository bundles the project's full workflow—from theoretical foundation and experimental setup to raw data and manuscripts:
- **`docs/`** – background, literature review, theoretical models, and documentation.
- **`code/`** – source code for problem generators, quantum/hybrid solvers, and driver scripts.
- **`gathered_data/`** – processed datasets, experiment logs, and key result files.
- **`raw_data/`** – unprocessed inputs, benchmarks, or output dumps.
- **`manuscripts/`** – drafts of research papers, reports, or presentations.
- **`unimelb_stuffs/`** – course-specific related content from the University of Melbourne.

Each subdirectory contains its own README with detailed instructions. Use the following sections to navigate through the project.
