# 1_cleaned data/

This directory stores the cleaned datasets, which are the outputs from the initial data cleaning process (typically from the `0_raw data/clean.py` script). It also contains the `isolate.py` script, which further processes these cleaned files to extract and format only the essential spatial information, preparing them for graph construction and VRP modeling.

---

## Contents

* `isolate.py`: A Python script designed to "digest" or isolate spatial-only information from the cleaned CSV files. It performs the following operations:
    * Reads cleaned CSV files (e.g., `public-litter-bins-clean.csv`).
    * For point data (litter bins, waste collection areas, facilities), it extracts `ID`, `Latitude`, and `Longitude`.
    * For road network data (`road-responsibility-clean.csv`), it processes the points to create distinct road segments (edges) with `ROAD_SEGMENT_ID`, `LINE_ID`, `START_LAT`, `START_LON`, `END_LAT`, and `END_LON`.
    * Saves the resulting spatial-only data to new CSV files with a semicolon delimiter.

* **Cleaned Data Files (Expected Inputs)**: This folder should contain the output files from the `0_raw data/clean.py` script:
    * `public-litter-bins-clean.csv`
    * `road-responsibility-clean.csv`
    * `waste-collection-area-clean.csv`
    * `waste-facility-locations-clean.csv`

* **Spatial-Only Data Files (Expected Outputs)**: After running `isolate.py`, the following spatial-only CSV files will be generated in this same directory:
    * `public-litter-bins-clean-spatial.csv`
    * `road-responsibility-clean-spatial.csv`
    * `waste-collection-area-clean-spatial.csv`
    * `waste-facility-locations-clean-spatial.csv`

---

## How to Use

To perform the spatial data digestion step:

1.  **Place Cleaned Data**: Ensure all the cleaned CSV files (listed under "Cleaned Data Files") are present in this `1_cleaned data/` directory alongside the `isolate.py` script. These files are typically generated by running `0_raw data/clean.py`.
2.  **Install Dependencies**: Make sure you have the necessary Python library installed. `isolate.py` uses `pandas`.
    ```bash
    pip install pandas
    ```
3.  **Run the Digestion Script**: Open your terminal or command prompt, navigate to the `1_cleaned data/` directory, and execute the script:
    ```bash
    python isolate.py
    ```
4.  **Verify Outputs**: After execution, new spatial-only CSV files will appear in this directory. These files are now streamlined with only the geographical information needed for graph construction.

---

## Purpose

The `isolate.py` script serves a crucial role in preparing the data for the core VRP modeling:

* **Focus on Spatial Data**: It distills the cleaned data down to only the essential geographical coordinates, removing extraneous columns that are not directly relevant to the VRP graph.
* **Graph Node/Edge Preparation**: For point data, it creates clear node representations (ID, Lat, Lon). For road data, it explicitly defines edges (segments) with start and end coordinates, making it ready for graph algorithms.
* **Efficiency**: By creating smaller, focused spatial datasets, it improves the efficiency of subsequent processing steps, especially when constructing the VRP graph and calculating distances.
* **Input for VRP Graph Construction**: The output files from this script are the direct inputs for building the VRP graph, which will then be used by the quantum optimization algorithms.
