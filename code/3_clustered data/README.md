# 3_clustered data/

This directory stores the results of the clustering process and contains the `complete_grapher.py` script. This script is responsible for constructing a detailed road network graph, mapping all relevant spatial points (facilities, waste areas, bins) to this network, and then generating complete graphs (distance matrices) for each identified cluster. These complete graphs are the direct input for the quantum optimization algorithms.

---

## Contents

* `complete_grapher.py`: A Python script that performs the following critical steps:
    1.  **Loads Input Data**: Reads the spatial-only CSV files (from `1_cleaned data`) and the clustering JSON files (from `2_isolated data`).
    2.  **Builds Road Network Graph**: Constructs a `networkx` graph from the `road-responsibility-clean-spatial.csv`, where nodes are unique geographical points on the road network and edges represent road segments with Haversine distances as weights.
    3.  **Maps Points to Road Nodes**: Maps all public litter bins, waste collection areas, and waste facilities to their nearest corresponding nodes on the constructed road network graph.
    4.  **Calculates Complete Graphs for Clusters**: For each cluster identified in the previous step (e.g., bins assigned to a waste area, or waste areas assigned to a facility), it calculates the all-pairs shortest path distances between all points within that cluster using the underlying road network. These distances form the "complete graph" or distance matrix for each cluster.
    The final output is a JSON file containing all generated distance matrices, structured by their respective clusters.

* **Expected Input Files**: This folder requires the following files to be present:
    * From `1_cleaned data/`:
        * `public-litter-bins-clean-spatial.csv`
        * `waste-collection-area-clean-spatial.csv`
        * `waste-facility-locations-clean-spatial.csv`
        * `road-responsibility-clean-spatial.csv`
    * From `2_isolated data/`:
        * `public_litter_bins_to_waste_collection_areas_clustering.json`
        * `waste_collection_areas_to_waste_facilities_clustering.json`

* **Expected Output File**: After running `complete_grapher.py`, the following JSON file will be generated in this same directory:
    * `cluster_complete_graphs.json`: Contains a structured collection of distance matrices for each cluster, representing the travel distances between all relevant points within that cluster via the road network.

## How to Use

To generate the complete graphs for your clusters:

1.  **Place Input Files**: Ensure all the necessary input CSV and JSON files (listed under "Expected Input Files") are present in this `3_clustered data/` directory alongside the `complete_grapher.py` script. These files are typically generated by running scripts in the `1_cleaned data/` and `2_isolated data/` directories.
2.  **Install Dependencies**: Make sure you have the necessary Python libraries installed. `complete_grapher.py` uses `pandas`, `numpy`, `networkx`, and `scipy`.
    ```bash
    pip install pandas numpy networkx scipy
    ```
3.  **Run the Grapher Script**: Open your terminal or command prompt, navigate to the `3_clustered data/` directory, and execute the script:
    ```bash
    python complete_grapher.py
    ```
4.  **Verify Output**: After execution, the `cluster_complete_graphs.json` file will appear in this directory. You can inspect its contents to see the generated distance matrices.

## Purpose

The `complete_grapher.py` script and its output are pivotal for the quantum optimization phase of the project:

* **Realistic Distance Calculation**: By using the actual road network and calculating shortest paths, this step ensures that the distances used in the VRP model are realistic and reflect actual travel constraints, rather than simple straight-line (Haversine) distances.
* **VRP Graph Formulation**: It transforms the raw and clustered spatial data into a formal graph representation (distance matrices) that is directly consumable by optimization algorithms, including quantum ones.
* **Problem Scaling**: The clustering, combined with this graph generation, allows for breaking down a large, complex VRP into more manageable sub-problems, each with its own complete graph. This is particularly important for quantum algorithms which are currently limited by qubit count.
* **Foundation for Optimization**: The generated distance matrices are the core input for defining the cost functions and Hamiltonians in quantum optimization algorithms like QAOA, enabling the search for optimal or near-optimal routes within each cluster.
