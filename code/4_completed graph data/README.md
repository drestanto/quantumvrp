# 4_completed graph data/

This directory serves as the stage for inspecting and performing initial, classical Vehicle Routing Problem (VRP) solutions on the complete graphs (distance matrices) generated in the previous `3_clustered data` step. It contains utility scripts to view the graph data and a basic brute-force VRP solver for individual clusters.

---

## Contents

* `cluster_complete_graphs.json`: (Expected Input) This JSON file is the primary input for all scripts in this folder. It contains the all-pairs shortest path distance matrices for each cluster (e.g., public litter bins within a waste collection area, or waste collection areas within a waste facility's service zone). This file is generated by `3_clustered data/complete_grapher.py`.

* `sample_digestor.py`:
    * **Purpose**: This script allows you to inspect the distance matrix for a *specific* cluster. You can choose a `cluster_type` ('waste_facility' or 'waste_collection_area') and a `target_id` to view its corresponding distance matrix in a readable format (Pandas DataFrame and NumPy array).
    * **Usage**: Useful for verifying the structure and values of individual cluster graphs. You will need to edit the `cluster_type` and `target_id` variables within the script before running it.

* `lookuper.py`:
    * **Purpose**: This script provides a quick overview of all the clusters present in `cluster_complete_graphs.json`. It lists each cluster's ID and the number of nodes (points) it contains, for both "Public Litter Bins to Waste Collection Areas" and "Waste Collection Areas to Waste Facilities" cluster types.
    * **Usage**: Ideal for getting a summary of the generated graph data and understanding the scale of each VRP sub-problem.

* `naive_vrp.py`:
    * **Purpose**: This script implements a basic brute-force VRP solver for a *single, user-defined cluster*. It calculates the optimal path and associated distance by exploring all possible permutations of customer visits within that cluster, starting and ending at the designated depot (the cluster's ID). It also provides statistics like worst distance, average distance, and potential savings.
    * **Usage**: Demonstrates a classical approach to solving the VRP on a small scale. Due to its brute-force nature, it is computationally intensive and **only suitable for very small clusters** (e.g., 5-8 nodes) before computation time becomes prohibitive. You will need to edit the `cluster_type` and `target_id` variables within the script to specify which cluster to solve.

---

## How to Use

All scripts in this folder require the `cluster_complete_graphs.json` file to be present in the same directory.

1.  **Ensure Input File**: Make sure `cluster_complete_graphs.json` (generated from `3_clustered data/complete_grapher.py`) is in this `4_completed graph data/` directory.

2.  **Install Dependencies**: Ensure you have the necessary Python libraries installed:
    ```bash
    pip install pandas numpy
    ```

3.  **Run `lookuper.py` (Optional, for overview)**:
    ```bash
    python lookuper.py
    ```
    This will print a summary of all clusters and their node counts to your console.

4.  **Run `sample_digestor.py` (Optional, for detailed inspection)**:
    * **Edit `sample_digestor.py`**: Open the script and modify the `cluster_type` and `target_id` variables to specify the cluster you wish to inspect.
    * **Execute**:
        ```bash
        python sample_digestor.py
        ```
    This will print the distance matrix for the selected cluster to your console.

5.  **Run `naive_vrp.py` (For VRP solution)**:
    * **Edit `naive_vrp.py`**: Open the script and modify the `cluster_type` and `target_id` variables to specify the cluster you want to solve. **Be mindful of cluster size for this script; large clusters will take an extremely long time to compute.**
    * **Execute**:
        ```bash
        python naive_vrp.py
        ```
    This will print the optimal path, minimum distance, and other statistics for the selected cluster to your console.

## Purpose

The scripts in this `4_completed graph data/` folder serve as crucial tools for:

* **Graph Validation**: Verifying that the `cluster_complete_graphs.json` file is correctly structured and contains the expected distance information.
* **Classical Baseline**: Providing a simple, brute-force classical solution to the VRP for small clusters. This serves as a fundamental benchmark against which future quantum optimization results can be compared.
* **Understanding Problem Complexity**: Highlighting the exponential computational challenges of classical VRP solvers, even for moderately sized instances, thereby underscoring the motivation for exploring quantum approaches.
* **Preparatory Analysis**: Allowing researchers to gain familiarity with the VRP sub-problems before moving to more advanced quantum algorithm implementations.
