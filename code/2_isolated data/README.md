# 2_isolated data/

This directory builds upon the `1_cleaned data` by taking the spatial-only datasets and performing initial clustering operations. It contains the `cluster.py` script, which assigns public litter bins to waste collection areas and waste collection areas to the nearest waste facilities. This step is crucial for grouping related customer nodes, which can simplify the VRP formulation for multi-depot or multi-vehicle scenarios.

---

## Contents

* `cluster.py`: A Python script that performs two main clustering tasks:
    1.  **Assigns Public Litter Bins to Waste Collection Areas**: For each public litter bin, it identifies the closest waste collection area (based on centroid coordinates) and assigns the bin to that area.
    2.  **Assigns Waste Collection Areas to Waste Facilities**: For each waste collection area, it identifies the closest waste facility and assigns the area to that facility.
    The script uses the Haversine formula to calculate geographical distances. The results of these assignments are saved as JSON files.

* **Spatial-Only Data Files (Expected Inputs)**: This folder should contain the output files from the `1_cleaned data/isolate.py` script:
    * `public-litter-bins-clean-spatial.csv`
    * `waste-collection-area-clean-spatial.csv`
    * `waste-facility-locations-clean-spatial.csv`
    * *(Note: `road-responsibility-clean-spatial.csv` is not directly used by `cluster.py` but is part of the isolated data.)*

* **Clustering Output Files (Expected Outputs)**: After running `cluster.py`, the following JSON files will be generated in this same directory:
    * `public_litter_bins_to_waste_collection_areas_clustering.json`
    * `waste_collection_areas_to_waste_facilities_clustering.json`

## How to Use

To perform the clustering step:

1.  **Place Spatial-Only Data**: Ensure all the spatial-only CSV files (listed under "Spatial-Only Data Files") are present in this `2_isolated data/` directory alongside the `cluster.py` script. These files are typically generated by running `1_cleaned data/isolate.py`.
2.  **Install Dependencies**: Make sure you have the necessary Python libraries installed. `cluster.py` uses `pandas` and `numpy`.
    ```bash
    pip install pandas numpy
    ```
3.  **Run the Clustering Script**: Open your terminal or command prompt, navigate to the `2_isolated data/` directory, and execute the script:
    ```bash
    python cluster.py
    ```
4.  **Verify Outputs**: After execution, new JSON files containing the clustering assignments will appear in this directory.

---

## Purpose

The `cluster.py` script and the outputs in this folder serve several key purposes:

* **Initial Grouping for VRP**: By clustering bins to areas and areas to facilities, this step provides a hierarchical grouping of customer nodes. This can be critical for simplifying complex VRP instances, especially when dealing with a large number of individual litter bins.
* **Defining Sub-problems**: The assignments can help in defining smaller, more manageable VRP sub-problems, where each waste facility is responsible for a specific set of waste collection areas, and each area is responsible for its assigned litter bins.
* **Optimizing Resource Allocation**: Understanding which areas are closest to which facilities helps in strategic planning for vehicle deployment and route optimization.
* **Input for Graph Construction (Advanced)**: The clustering results can inform the construction of a more sophisticated VRP graph, where customer nodes might represent clusters rather than individual points, or where initial assignments guide the overall routing strategy.
